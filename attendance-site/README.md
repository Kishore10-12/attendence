# Section K Attendance Calculator

A static site: no build step, no server.

Deploy on Render
1. Put these files in a GitHub repository (index.html at the top level).
2. Render dashboard > New > Static Site > pick the repository.
3. Build Command: leave empty (or `echo ok`). Publish Directory: `.`
4. Create. Render gives you an https link to share.

Install on a phone
- Android (Chrome): menu > Install app.
- iPhone (Safari): Share > Add to Home Screen.
